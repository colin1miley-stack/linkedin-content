# LinkedIn Message Type Reference — Revenue Systems Outreach

> **Created:** 2026-08-31
> **Purpose:** Log LinkedIn message constraints by interaction type so future outreach respects format limits.

---

## Message Types & Constraints

| Type | How to Access | Subject Line | Body Length | Best For |
|------|---------------|--------------|-------------|----------|
| **Follow + Message** | Follow someone first, then message from their profile | ✅ Yes — required | Large text box (~2,000+ chars) | Warm leads, visible CEOs, people who don't accept cold connections |
| **Connection Request + Message** | Click "Connect" and add a note | ❌ No | **Hard limit: 300 characters** | Cold outreach, first contact, high-volume targets |
| **InMail (Sales Navigator)** | Send via Sales Nav | ✅ Yes | ~200 chars (free) / longer (paid) | Premium targets, paid outreach |
| **Open Profile Message** | Message open profiles without connecting | ❌ No | ~300 chars | Rare — only if profile is explicitly open |

---

## Key Rules

### Connection Request Messages (300 char limit)
- **No subject line** — the note appears as plain text under the connection request
- Count includes spaces and punctuation
- Must include: greeting, personalisation, value hint, soft CTA, sign-off
- Always run through a character counter before delivering

### Follow Messages (large text box)
- **Subject line required** — this is the email-style header
- Body can be 3–5 sentences
- More room for specificity and proof
- Still keep it tight — executives skim

## Currency & Location Rules

### 🇮🇪 Irish Companies = EUR (€)
- **Never use USD ($) for Irish companies** — unprofessional, signals you didn't do basic homework
- Convert USD figures to EUR or omit currency entirely
- If source data is in USD, convert at rough rate (€1 ≈ $1.08) or round to clean EUR numbers
- Applies to: revenue, funding, team size (headcount is fine)

### 🇪🇺 European Companies (non-Irish)
- Use EUR for Eurozone companies
- Use GBP (£) for UK companies
- Use local currency unless company explicitly reports in USD

### 🇺🇸 US Companies
- USD is fine
- Still verify — some report in EUR if they have significant EU presence

### Rule of Thumb
> If the company is headquartered in Dublin, Cork, Galway, or Limerick — the message references EUR. Full stop.

## RDDS Message Templates by Type

```
Subject: [Specific observation about their company]

Hi [Name], [Company] hit [milestone] — that's serious velocity. That speed usually creates a gap between sales process and proof. Most teams know they leak revenue but can't prove where.

I run forensic diagnostics on B2B pipelines: ingest CRM data, output evidence-based proof-assets showing exactly where money leaks and what fixing it returns. Not a deck. Not a benchmark report. Your data, your leaks, your ROI.

Worth a 10-min chat, or am I off-base for [Company]? — Colin
```

```
Hi [Name], [Company] is at [milestone] now — impressive. That growth usually creates a gap between process and proof. I run forensic pipeline diagnostics for Irish B2B teams (actual CRM data → proof-assets, not generic reports). Worth a 10-min chat, or am I off-base? — Colin
```
