# LinkedIn Outreach — Skill Context (Layer 1)

## Purpose
Execute LinkedIn Sales Navigator outreach for B2B sales services. 5 outreaches/day. Target: 20 companies. Goal: 1 pilot client in 4 weeks.

## Routing
- Read `SKILL.md` for message templates and sequences (Layer 2)
- Read `references/outreach-tracker.md` for daily tracking (Layer 3)
- Read `references/target-list.md` for target accounts (Layer 3)
- Read `references/message-performance.md` for A/B results (Layer 3)
- Read `~/ops/BRANDS/colin-main.canon.md` for CTA template (Layer 3 — external)
- Working artifacts go to `output/` (Layer 4)

## When to Use
- Writing connection requests or follow-up sequences
- Planning outreach campaigns
- Target list building
- Message personalisation
- Response handling
- Triggers: "outreach", "linkedin message", "connection request", "follow up"

## When NOT to Use
- Automating messages (prohibited — every message must be personalised)
- Mass messaging without individual research

## Dependencies
- `colin-brand-guard` skill (canon alignment for all outbound text)
- `client-memory` skill (for tracking conversations)

## Critical Rules
- **Never automate.** Every message personalised. No bots.
- **One CTA per message.** Never ask for call + download + follow.
- **Respond within 2 hours.** Speed signals professionalism.
- **Log everything.** What works, what doesn't, what to iterate.
- **Declined connections = removed.** Do not follow up.
